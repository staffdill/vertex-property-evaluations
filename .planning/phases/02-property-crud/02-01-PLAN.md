    **Step 3: Create app/routers/properties.py**

    Use the exact patterns from the research document:

    - `router = APIRouter(prefix="/api/properties", tags=["properties"])`
    - `get_connection()` async generator: calls `get_db()`, yields conn, closes in finally
    - `POST /`: `create_property(body: PropertyCreate, conn = Depends(get_connection))` — INSERT, commit, SELECT back, return `dict(row)` with status_code=201
    - `GET /`: `list_properties(conn = Depends(get_connection))` — LEFT JOIN assets COUNT, GROUP BY, ORDER BY created_at DESC, NULL AS risk_badge, return `[dict(r) for r in rows]`
    - `GET /{property_id}`: `get_property(...)` — SELECT property, 404 if not found, SELECT assets WHERE property_id, return dict with "assets" key
    - `DELETE /{property_id}`: `delete_property(...)` — SELECT to check existence (404 if not found), DELETE, commit, return Response(status_code=204)

    CRITICAL for delete: Return `Response(status_code=204)` (from `fastapi import Response`), not just `status_code=204` on the decorator. FastAPI returns content on DELETE unless you explicitly return a Response with no body.

    CRITICAL for foreign keys cascade: The `get_connection()` generator calls `get_db()` which already sets `PRAGMA foreign_keys=ON`. Never bypass `get_db()` with a direct `aiosqlite.connect()` call.

    CRITICAL: Always convert aiosqlite.Row → dict before returning. Never return a raw Row object.
